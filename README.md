# 👕 ReWear AI 

An AI-powered sustainable fashion marketplace where users can buy, sell, and swap pre-owned clothes while getting smart AI-based recommendations and pricing insights.

---

## 🌍 Vision

Fast fashion creates massive waste and pollution.  
ReWear AI aims to make sustainable fashion accessible, affordable, and intelligent through AI-driven experiences.

---

## ✨ Features

### 🛒 Marketplace
- Buy thrift clothing
- Sell old clothes
- Swap outfits with other users
- Wishlist & saved items

### 🤖 AI Features
- AI outfit recommendations
- AI-based price estimation
- Smart product categorization
- Personalized feed
- Future AI virtual try-on system

### 📱 User Experience
- Responsive modern UI
- Clean product browsing
- Search & filtering
- Mobile-friendly design

---

## 🧠 Tech Stack

### Frontend
- React.js / Next.js

### Backend
